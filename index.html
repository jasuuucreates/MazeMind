Maze Evolution

A genetic algorithm breeds mazes. Each maze's fitness is measured with A*: a long escape route, many dead ends and a few escape loops make a maze "fitter".

What the designer wants

Fitness weights. Change them and evolve again to breed a different kind of maze.

One generation

1. Evaluate: decode each chromosome into a maze, run A* from start to exit, count dead ends and loops.

2. Elitism: the 2 fittest mazes are copied unchanged.

3. Selection: tournament of 3 random mazes, the fittest becomes a parent.

4. Crossover: uniform, each passage bit comes from one of the two parents.

5. Mutation: each bit flips (wall ↔ passage) with the mutation rate.

How it works

MazeMind uses three AI techniques from the syllabus: heuristic search (A*, compared with BFS, DFS and greedy best-first), fuzzy logic and a genetic algorithm.

What a hunter does on every step

1. SenseA* measures the real distance to the player through the maze.
2. FeelFuzzy logic turns distance + energy into an aggression value.
3. DecideAggression ≥ 62: CHASE, ≥ 38: AMBUSH (cut you off), else PATROL or REST.
4. PlanThe chosen search algorithm plans a route to the target.
5. ActTake one step. Chasing costs energy, resting restores it.

g(n) = steps from the start to n, h(n) = estimated steps from n to the goal. We use the Manhattan distance |x1 − x2| + |y1 − y2|: you can only move up, down, left or right, so the true distance is never shorter. The heuristic is admissible (never overestimates) and consistent, which is why A* returns the shortest path while expanding fewer cells than BFS. Try it in the Search Lab.

2. Fuzzy logic: the hunter's mood (Mamdani inference)

Instead of hard rules like "if distance < 8 then chase", each input belongs to several sets partly. A distance of 7 steps is a little NEAR and a little MEDIUM at the same time, so the hunter's behaviour changes smoothly.

Steps: (1) fuzzify both inputs with the triangle/trapezoid membership functions; (2) each of the 9 rules fires with strength = min of its two memberships (fuzzy AND); (3) each rule clips its output set at that strength; (4) the clipped sets are combined with max; (5) defuzzify with the centroid (centre of gravity) to get one number.

3. Genetic algorithm: breeding harder mazes

Chromosome: one bit for every place where two neighbouring rooms could be joined: 1 = passage, 0 = wall. A 14 × 9 maze has 13×9 + 14×8 = 229 genes.

Fitness: mazes whose exit cannot be reached score below 0.25. Solvable mazes score 0.25 + reach² × (weighted mix of A* route length, dead ends and escape loops), where reach = share of rooms connected to the start and loops = passages − rooms + 1.

Operators: elitism (keep the best 2), tournament selection (size 3), uniform crossover (rate 0.9), bit-flip mutation (rate 1%). The search algorithm is reused inside the fitness function, which links the two halves of the project. Watch it in Maze Evolution.
